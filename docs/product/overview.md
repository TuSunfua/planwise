# Product overview

## Vision

**Plan on your own. Get it done together.**

Personal task apps often break down when a second person joins, and team tools are often too heavy for one person. PlanWise starts as a fast personal planner and lets any project become shared, without moving data or switching tools.

## Who it is for

| User | Needs | Phase |
| --- | --- | --- |
| Solo planner: student, freelancer, maker | Capture quickly, know what to do today, see progress by project | 1 |
| Project owner | Share one project while keeping the others private | 2 |
| Collaborator | Know what is assigned to them and what changed | 2 |

## Principles

1. **Capture first.** A task needs only a title.
2. **Today is clear.** The app always answers "what should I do now?"
3. **Private by default.** Nothing is shared until its owner invites someone.
4. **Solo stays simple.** Collaboration controls appear only when they are useful.
5. **Projects are the sharing boundary.** Access is granted per project, never to a whole account.
6. **Fast and accessible.** Keyboard, touch and screen readers are all first-class.

## Vocabulary

Use these terms in UI, code and docs.

| Term | Meaning | Avoid |
| --- | --- | --- |
| Task | One unit of work | Todo, item, ticket, card |
| Subtask | A task under another task, one level deep | Child task |
| Project | A container of tasks and the unit of sharing | List, space |
| Inbox | A user's built-in project, which can never be shared | Default project |
| Label | A colored tag within a project | Tag, category |
| Member | A user with a role in a project | Participant |
| Assignee | A member responsible for a task | Owner |
| Owner | The role that controls a project | Admin |
| Planned date | The day the user intends to work on a task | Start date |
| Due date | The day a task must be finished | Deadline |

## Initial targets

These are starting hypotheses, to revisit once there is real usage.

| Measure | Target |
| --- | --- |
| New users who create a task in their first session | At least 70% |
| New users active again in week 4 | At least 25% |
| Time to capture a task from anywhere in the app | Under 5 seconds |
| Shared projects with two or more active members (Phase 2) | At least 50% |

## Not planned in either phase

Native mobile apps, organizations and billing, Gantt charts, time tracking, custom workflow builders, AI features, languages other than English and third-party integrations.
